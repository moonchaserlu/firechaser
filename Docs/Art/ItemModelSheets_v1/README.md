# 物品建模三视图 v1

使用内置 imagegen，以游戏现有图标为造型参考生成。

已保存 17 件；short_knife、fuel_pack 在初次及重试中均被图像服务以 violence 类别拦截，尚缺。

版式：TOP 俯视在左上，FRONT 主视在左下，RIGHT 侧视在右下。手枪以侧面为主视。

这些是概念建模参考，非经过三维模型验证的精确工程投影。部分页面仍含轻微俯角、跨视图比例或细节差异，尤其废金属堆、绷带尾部、瓶口布条和零件组合。建模时需统一同一模型的厚度、遮挡和部件位置，不应逐像素照描所有视图。

12G、5.56 为单发建模参考，完成单体后复制成图标组合。9mm 保留组合参考。怀表表盖展开以展示厚度。

原游戏图标未改动。manifest.json 保存最终提示词与源文件路径。index.html 为预览目录。
