# 游戏设计简案 V0.1

## 一句话概念

玩家从幸存者营地进入不断恶化的荒野，在饥饿、黑暗和怪物的压力下搜刽物资，并在背包塞满之前找到回家的路。

## 类型与体验

- 类型：2.5D 俯视角 PvE 搜打撤 + 生存建造
- 平台：PC
- 模式：单人优先，未来可扩展 2–4 人合作
- 单局目标时长：20–40 分钟
- 美术方向：卡通低多边形、荒诞、略带诡异感

## 核心系统

- 生命、饥饿、精神和体力。
- 格子背包与负重，负重影响移动、体力和撤离速度。
- 近战、远程、翻滚、声音引怪和环境利用。
- 昼夜循环、恶劣天气与精神幻觉。
- 固定、条件、临时和紧急撤离点。
- 死亡掉落、安全袋和后续尸体回收。
- 工作台、厨房、仓库、火种核心与幸存者营地。

## MVP 验证问题

当玩家背包已经装满，而夜晚即将到来时，是否会认真纠结继续深入还是立即撤离？

若这个抉择稳定产生紧张感和故事，核心玩法成立。
