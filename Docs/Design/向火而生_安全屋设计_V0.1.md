# 《向火而生》安全屋（庇护所）设计 V0.1

> 日期：2026-10-30　状态：主创已确认方向；第一版范围已收窄

**第一版范围（主创 2026-10-30 确认）**：安全屋位于地下；只做**靶场、仓库、工作台**，外加通往地面的楼梯出口用于出发。交易台、床铺、电力间和设施升级都先不做，下文第 3、4 节保留为远期参考。Map01 东南角小屋改为前哨与登陆点。
> 方向：主创选定“独立安全屋场景”，参考塔科夫藏身处、逃离鸭科夫据点的**公开玩法思路**（局外据点、设施升级、出发与带回），内容与美术为本作原创。

## 1. 定位

安全屋是两次远行之间的家：一座被寻火者重新点燃的废弃庇护所。外面永远黑暗，只有屋里的炉火和灯是安全的。玩家在这里整理收获、修补装备、升级设施，然后带着选好的物资出发去 Map01（以后还有更多地图）。

与局内的关系：

```text
安全屋（局外，常驻）
  → 地图桌选择目的地、带上物资
  → Map01（局内：搜刮、躲黑暗、撤离）
  → 撤离成功：背包物资带回安全屋仓库
  → 死亡：带出去的物资全部丢失，回到安全屋
```

## 2. 设计原则

1. **光就是家**：安全屋本身也受黑暗规则约束。炉火和电灯照到的地方才安全，设施升级会让“家”变大变亮，这是本作对“藏身处升级”的原创表达。
2. **一切进步都来自远行**：设施升级只消耗从地图带回来的物资（燃料、零件、电池、布料、身份牌等），让每次搜刮都有明确去处。
3. **出发是有代价的选择**：带出去的东西可能丢，留在仓库的东西才安全。
4. **局内规则不变**：安全屋不改动黑暗伤害、火堆、怪物等局内规则，只决定“带什么进去、带回来能做什么”。

## 3. 空间布局（单层，可整体逛完约 40×30 米）

| 区域 | 用途 | 初始状态 |
|---|---|---|
| 炉火（中心） | 安全屋核心光源；决定屋内安全范围；升级入口 | 小火，只照亮中心 |
| 仓库 | 局外物资存放，跨局保留、存档 | 容量小 |
| 工作台 | 沿用现有合成 | 基础配方 |
| 回收与交易台 | 卖回收物换价值、买基础补给 | 可用 |
| 电力间 | 安装充好的电池，供电点亮电灯和高级设施 | 断电 |
| 床铺 | 回家后恢复生命 | 可用 |
| 地图桌（出口） | 选择目的地、确认携带物资、出发 | 可用，只有 Map01 |
| 记录墙 | 任务记录、旧地图、远行日志 | 可用 |

外围（黑暗）：一圈被木板封住的窗和门，屋外是看得见但走不出去的黑暗荒地，强调“家只有这一圈光”。

## 4. 设施升级（类似藏身处模块，原创内容）

| 设施 | 等级与花费（草案） | 效果 |
|---|---|---|
| 炉火 | Lv2：燃料×4、布料×2；Lv3：燃料×8、机械零件×2 | 屋内安全光扩大，点亮更多区域；出发时免费带 1/2 份燃料 |
| 仓库 | Lv2：废金属×6；Lv3：废金属×10、机械零件×3 | 仓库格数 24 → 40 → 64 |
| 工作台 | Lv2：机械零件×3、化学品×2 | 解锁更多配方 |
| 电力间 | Lv1：充好的电池×1；Lv2：再×2 | 点亮电灯（整间安全）；解锁交易台进阶商品 |
| 床铺 | Lv2：布料×4、罐头×2 | 回家后完全恢复，并去除流血 |
| 背包架 | Lv2：布料×3、废金属×4 | 出发时背包 +2 格 |

规则：设施有前置（如工作台 Lv2 需要电力间 Lv1）；升级立即生效；数值全部做成可配置数据表。

## 5. 存档

- 仓库、价值、设施等级、任务进度写入本地存档（JSON，Application.persistentDataPath），关游戏也保留。
- 局内状态不存档：中途退出视为放弃本局（带出的物资丢失）。

## 6. 与现有 Map01 的关系（需要确认）

Map01 东南角现在的小屋同时承担出生点、回收、商店、工作台和任务链里的“庇护所”。有了独立安全屋后，默认这样处理：

- Map01 小屋改为**前哨/登陆点**：出生点和返程撤离仍在这里，保留炉火和安全光；回收、商店、工作台搬到安全屋。
- 任务链 Q01–Q10 暂时留在 Map01 不动，第二阶段再决定是否把“庇护所”相关的任务（Q01、Q02、Q04、Q10）搬到安全屋。
