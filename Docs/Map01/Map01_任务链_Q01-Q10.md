# Map01 任务链 Q01–Q10（实现说明）

> 日期：2026-10-27　分支：`claude/map01-whitebox`（未提交）　依据：`Docs/Design/向火而生_前10个任务草案.md`

## 结构

| 部分 | 文件 | 作用 |
|---|---|---|
| 任务配置 | `Assets/Map01/Data/Map01_QuestChain.asset`（类型 `Map01QuestChain`） | 任务名、目标、每一步目标文案、完成提示、四份记录全文与位置、保底物资、Q06/Q08 区域、炉火半径、开局是否收走燃料。只在缺失时由编辑器生成，之后重建场景不会覆盖 |
| 状态规则 | `Runtime/Quest/QuestChainModel.cs` | 纯 C#：未开启 / 进行中 / 已完成，按顺序推进；每个任务由一个“事实”完成，事实可提前获得，任务开启时直接认可，同一事实只记一次 |
| 任务导演 | `Runtime/Quest/Map01QuestDirector.cs`（挂在 `Map01_Game`） | 把现有状态翻译成事实；处理炉火、记录、旧地图交互；刷保底物资；切换庇护所照明 |
| 任务模式开关 | `Map01Authority.questMode`（场景中已开） | 开：第一块充好的电池只用于恢复庇护所照明，不计入救援电量；关：原救援循环，庇护所常亮，任务交互点隐藏 |
| 阅读 | `Map01RunFlow.OpenReading` | 沿用暂停：时间冻结、操作关闭，黑暗与怪物不推进；E 或 Esc 合上 |
| HUD | `Map01Hud` | 右上角任务名与当前一步目标、完成提示；阅读面板；左上角“庇护所照明”状态 |
| 场景搭建 | `Editor/Map01QuestSetup.cs`（由 `Map01GameplaySetup` 调用） | 炉火灯、室内电灯、记录与旧地图交互点、视觉陈设；按配置资产里的位置摆放 |

## 完成条件（事实）

| 任务 | 事实 | 来源 | 容错 |
|---|---|---|---|
| Q01 火不能灭 | `fuel_delivered` | Q01 进行中在炉火按 E，扣 1 份燃料 | 无燃料时失败、不扣；完成后炉火不再收燃料 |
| Q02 让这里亮起来 | `safehouse_lit` | 任务模式下第一块充好的电池装进供电槽 | 任意时间装都认可；厂房亮灯不算完成；不加救援电量、不激活撤离点 |
| Q03 备一点药 | `medical_confirmed` | Q03 进行中在炉火按 E，背包有带 Medical 标签的物品 | 只检查不扣除 |
| Q04 / Q05 / Q07 / Q09 | `record:<记录 ID>` | 阅读对应记录 | 提前阅读保存，开启时直接认可；重复阅读不重复推进 |
| Q06 到桥那边去 | `crossed_bridge` | 玩家进入桥北岸区域（任何时候） | 不要求击杀 |
| Q08 为返程留一盏火 | `campfire_at_bridge` | Q08 进行中，区域内有燃烧中的火堆（含开启前已建好的） | 火堆仍走原有燃尽规则 |
| Q10 下一段路 | `map_compared` | Q10 进行中在旧地图按 E | 不结束本局，不切地图 |

## 每一步目标（`steps` 下标含义）

- Q01：0 找燃料；1 身上有燃料，回炉火提交
- Q02：0 找零件；1 有零件，去修发电机；2 修理中；3 发电机已修好，需要空电池；4 有空电池或正在充电；5 有充好的电池，回庇护所安装
- Q03：0 找医疗用品；1 有医疗用品，回炉火清点
- Q08：0 找燃料；1 有燃料，去区域建火
- 其他任务只用第 0 条

## 试玩步骤

打开 `Wilderness/Map01/Open Map01`，进入 Play。WASD 移动，E 交互 / 搜索，Q 建火（左键确认），Esc 暂停。

1. Q01：出生在炉火光圈里，背包没有燃料。出北门绕到庇护所东侧外墙，搜索“物资堆”拿燃料，回炉火按 E。
2. Q02：庇护所北墙边“电池箱”里拿空电池。去西北的厂房，大厅西侧“零件箱”拿机械零件，到发电机房按 E 修理（留在旁边 4 秒）。厂房亮灯后等发电机存电，按 E 给空电池充电（3 秒）。回庇护所东墙供电槽按 E：室内灯亮，整间屋子算安全，撤离点不会激活。
3. Q03：回厂房大厅西侧“急救箱”拿急救喷雾（已有药品可跳过），回炉火按 E 清点，药品留在背包。
4. Q04：庇护所西墙边的记录按 E 阅读，E 或 Esc 合上。
5. Q05：去西边树林，林间小路尽头熄灭的旧火堆旁读笔记。
6. Q06：沿主路北上过桥，进入桥北引道即完成，桥头怪物可以绕开。
7. Q07：沿北岸主路往东到房区，进入唯一能进的住宅，读桌旁的日记。
8. Q08：回桥北头，在西侧空地按 Q 建火（桥北头备有一份燃料）。
9. Q09：往西到仓库，在东侧货箱旁读运送记录。
10. Q10：回庇护所，在东墙旧地图按 E，任务链收尾，右上角显示“任务完成”。
