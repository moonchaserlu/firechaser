# Map01 阶段 1：白盒场景

> 日期：2026-10-23　分支：`claude/map01-whitebox`　依据：《地图01_3D素材与Claude实现指南.md》第 6、7、10 节

## 生成与打开

- 菜单 `Wilderness/Map01/Build Map01 Whitebox`：重建场景 `Assets/Map01/Scenes/Map01.unity`、地形、河面网格和 NavMesh。可重复运行；已有材质保留，便于直接调色。
- 菜单 `Wilderness/Map01/Open Map01`：打开场景。
- 菜单 `Wilderness/Map01/Capture Whitebox Screenshots`：输出俯视图和厂房屋顶对比图。
- 命令行：`Unity.exe -batchmode -projectPath Game -executeMethod WildernessExtraction.Map01.EditorTools.Map01Builder.Build -quit`
- 场景**没有**加入 Build Settings，避免改动现有设置；测试按路径加载。

## 内容

| 项 | 实现 |
|---|---|
| 尺寸 | 480m × 320m，原点居中，概念图顶部 = +Z；`Map01Layout.PixelToWorld` 按指南公式换算 |
| 蓝图 | `BlueprintReference` 平面贴概念图，EditorOnly，运行时自动隐藏 |
| 地形 | Unity Terrain；中部山体最高约 16m，坡度不超过约 32°；建筑地基压平；道路与广场按像素折线刷到地形图层 |
| 河 | 河面网格标记为不可行走；两岸隐形挡墙阻挡玩家，只在桥面宽度处开口 |
| 桥 | 8m 宽桥面 + 两侧护栏，是唯一过河通道 |
| 可进入建筑 | 仓库、厂房（含发电机房）、房区住宅 A、主安全屋 |
| 不可进入建筑 | 房区其余 5 栋住宅体块 |
| 树林 | 固定种子散布约 400 棵占位树，避开道路、河、桥头、建筑和点位 |
| 点位 | 24 个 `MapSpawnPoint`，ID 形如 `map01_factory_generator_01`，定义集中在 `Map01Layout.Points` |
| 玩家 | 复用 `Assets/Game/Prefabs/Player.prefab`，出生在主安全屋；白盒阶段关闭了黑暗暴露伤害 |

### 建筑分层与屋顶显隐

```text
BuildingRoot (BuildingReveal)
  ExteriorLower      外墙视觉，始终显示
  InteriorVisuals    地板、隔墙、陈设视觉
  RoofRevealGroup    屋顶 Renderer，只有这里会被隐藏
  Physics            墙、隔墙、陈设的碰撞，与视觉分离
  Navigation
  InteriorVolumes    盒形室内判定体（不用 Collider，不进烘焙）
  EntrancePortals / LootSpawns / EventSpawns
```

- `RevealViewer` 标记本机玩家。只有 `IsLocal = true` 的观察者会让屋顶隐藏；屋顶状态不联网。
- 多个判定体取并集，门口和重叠房间不会闪烁；离开后等 0.1 秒再恢复。
- 原型阶段用 `Renderer.forceRenderingOff` 直接切换；阶段 2 替换为 0.15–0.30 秒抖动溶解。

## 验证

| 测试集 | 结果 |
|---|---|
| Map01 EditMode（布局数据） | 6/6 通过 |
| Map01 PlayMode（场景） | 9/9 通过 |
| 全工程 EditMode | 87/87 通过（原 81 + Map01 6） |
| 全工程 PlayMode | 38/38 通过（原 29 + Map01 9） |

PlayMode 覆盖：
- 24 个点位都在 NavMesh 上，并且都能从安全屋往返。
- 河面任意处都不可行走；AI 从西侧南岸到北岸的路径只经过桥面。
- 玩家角色控制器在河岸处被挡住，走桥可以到北岸。
- 进入厂房后只隐藏屋顶，碰撞全部保留；穿过大厅和发电机房之间的门洞时屋顶不闪回；离开后恢复。
- 屋内站着非本机玩家时，屋外本机玩家仍然看到屋顶。
- 所有可进入建筑都有独立屋顶和室内判定体。
