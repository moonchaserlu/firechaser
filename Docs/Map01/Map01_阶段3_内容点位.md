## 数据

| 资产 | 内容 |
|---|---|
| `Assets/Map01/Data/Map01_MapDefinition.asset` | 地图 ID、版本、范围、主安全屋、24 个点位（稳定 ID、类型、位置、标签、容量、所在建筑、路径长度、深度档位）。重建场景时自动刷新点位，保留策划改过的档位阈值 |

## 深度档位

按主安全屋出发的 NavMesh 最短可行路径长度计算，不用直线距离。临时阈值：≤ 90m 为 Tier 0，≤ 360m 为 Tier 1，其余为 Tier 2。

| 区域 | 路径长度 | 档位 |
|---|---:|---|
| 主安全屋 | 0m | 0 |
| 厂房、发电机 | 177–197m | 1 |
| 山体 | 195–223m | 1 |
| 桥南事件点 / 桥北守卫 | 256m / 312m | 1 |
| 树林 | 314–349m | 1 |
| 西南撤离点 | 385m | 2 |
| 仓库 | 436–461m | 2 |
| 房区住宅 A | 451–457m | 2 |
| 西北撤离点 | 553m | 2 |

**与指南暂定分档的差异**：指南把房区列为 Tier 1，但按路径长度，房区和仓库一样都要过桥，距离几乎相同（约 450m），所以算出来是 Tier 2。指南要求按路径深度分档，我保留了计算结果；如果你希望房区更安全，可以调阈值或移动房区位置。

## 生成器

`ContentGenerator.Generate(map, tables, seed)` 是纯 C# 逻辑，以后放在服务器上运行：

- 同一种子结果完全相同；点位按 ID 排序，每个点用自己的子种子，增删其他点不影响它。
- 地图几何与点位不随种子变化，只改变物资、怪物、可选事件、特殊房间和本局撤离点。
- 厂房发电机事件每局必出；Tier 0 不刷怪；撤离点在两个候选中选一个，救援完成前不可用。
