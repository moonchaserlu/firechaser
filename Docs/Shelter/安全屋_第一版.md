# 地下安全屋 第一版（靶场 + 仓库 + 工作台）

> 日期：2026-10-30　依据：`Docs/Design/向火而生_安全屋设计_V0.1.md`（第一版范围）

## 打开与生成

- 菜单 `Wilderness/Shelter/Build Shelter` 生成 `Assets/Shelter/Scenes/Shelter.unity`；`Wilderness/Shelter/Open Shelter` 打开。
- 从安全屋点 Play 开始；按 F（E 备用）与设施交互，Esc 关面板。
- 场景未登记 Build Settings；编辑器里由 `ShelterPlayModeLoad` 按路径切换场景。出独立包前需要把 Shelter 和 Map01 加进 Build Settings。

## 布局

中央炉火大厅（出生点）→ 西侧仓库、东侧工坊（工作台）、北侧楼梯间（出口）、南侧靶场。镜头一侧（南墙）做矮，能看进屋里。所有房间有灯，安全屋同样遵守黑暗规则。

## 功能

| 设施 | 作用 |
|---|---|
| 仓库 | 仓库 ↔ 背包逐件搬运；24 格；每次改动立即存档 |
| 工作台 | 沿用现有配方表，用背包里的材料合成；安全屋里配方全部可用 |
| 靶场 | 安全屋里唯一能开枪的地方；三块靶子约 8、10、12 米，打中记命中和伤害、打不坏；用练习弹：不消耗背包子弹，但弹匣照常会打空、要换弹（`PlayerShooter.FreeAmmo`） |
| 楼梯（出口） | 显示将带上的东西，确认后出发去 Map01 |

## 与 Map01 的衔接

- 出发：背包里的东西就是带进 Map01 的全部物资（任务模式也不再收走燃料）。
- Map01 东南角小屋改为前哨与登陆点：从安全屋出发时，小屋里的回收台、商店和工作台隐藏。
- 返回：离开前哨 25 米以上后，回到小屋北门外停留 3 秒，带着背包回到安全屋，物资进仓库（放不下的留在背包）。救援撤离同样带回。
- 死亡：带出去的东西全部丢失，回到安全屋。
- 直接打开 Map01（不经安全屋）时保持原来的单局玩法。

## 存档

`Application.persistentDataPath/firechaser_profile.json`：仓库物品、远行次数。新档时仓库里有初始物资（手枪、短刀、燃料包 ×2、9mm ×8、脏绷带）。
